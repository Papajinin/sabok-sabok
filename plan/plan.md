# 사복사복 (SABOK SABOK) 기획안

> 사회복지사 1급 기출문제 연습 앱. "사회복지사(사복)를 사복사복 즈려밟자"
> 사용자(아빠) 혼자 쓰는 **개인 앱** (가족 AIN 앱 아님, AIN 디자인 규칙 안 따름). 결정사항은 `decisions.md`가 우선.

## 1. 무엇을, 왜

- 시험 대비 혼자 공부. 2020~2026년 기출(연도는 파일이 오는 대로 추가), 한 해 200문제
- 아이폰 Safari "홈 화면에 추가" + 맥에서도. 풀던 기록은 기기끼리 이어짐

## 2. 시험 구성 (문제 번호로 과목을 나눔)

| 교시 | 문제 | 과목 (25문제씩) |
|---|---|---|
| 1교시 사회복지기초 | 50 | 인간행동과 사회환경 1~25, 사회복지조사론 26~50 |
| 2교시 사회복지실천 | 75 | 사회복지실천론 1~25, 실천기술론 26~50, 지역사회복지론 51~75 |
| 3교시 사회복지정책과 제도 | 75 | 사회복지정책론 1~25, 행정론 26~50, 법제론 51~75 |

합격: 모든 과목 40점 이상 + 전체 평균 60점 이상 (과목 점수 = 맞힌 수 ÷ 25 × 100)

## 3. 화면

아래 탭 5개: **홈 · 오답 · 검색 · 모의고사 · 기록**

1. **시작 화면:** 남색 바탕, 위로 걸어가는 흰 신발 발자국 2개, SABOK SABOK, 合格 도장, 노란 띠지 "2027 합격 대비 · 사회복지사 1급 기출"
2. **홈:** D-day, 회독 진행 막대, 이어 풀기, 과목·연도(여러 개 고르기)·문제 수(10/25/50/직접)·순서(안 푼 것 먼저/무작위/시험지 순서) → 풀기 시작
3. **문제 풀기:** 답을 누르면 바로 채점 (내 답 빨강, 정답 초록). [오답노트에 넣기 → 틀림/헷갈림], [AI 질문 복사], [다음 문제]. 다 풀면 결과(맞힌 수, 틀린 문제 목록)
4. **오답노트:** 전체/틀림/헷갈림, 과목 거르기, 오답만 풀기, 문제마다 빼기. **넣기·빼기는 버튼으로만** (자동 없음)
5. **검색:** 낱말로 문제·보기 찾기 (띄어쓰기 달라도 찾음)
6. **모의고사:** 연도 + 교시 고르기, 실제 시간(1교시 50분, 2·3교시 75분). 다 풀고 제출하면 과목별 점수·과락·합격 판정
7. **기록:** 과목별 정답률(초기화 가능), 회독 기록, 모의고사 기록, 시험 날짜(D-day), 계정

## 4. 회독

- 이번 회독에서 안 푼 문제가 먼저 나옴. 모든 문제를 한 번씩 풀면 "N회독 완료" → 다음 회독 시작 (지난 기록은 남음)

## 5. AI 질문 복사

문제, 상자(ㄱ·ㄴ·ㄷ), 보기, 정답, 내가 고른 답, "왜 그런지 쉽게 설명해 줘"를 글자로 복사 → Claude·ChatGPT에 붙여 넣기
